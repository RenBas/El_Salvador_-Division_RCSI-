# CDR Twin - Research Culture Sustainability Index

A Streamlit application for analyzing and simulating research culture sustainability in schools.

## Quick Start

**IMPORTANT:** Always run this application using Streamlit, NOT Python directly.

### Correct Way to Run:
```bash
streamlit run app.py
```

### ❌ Incorrect Way (will cause errors):
```bash
python app.py  # DO NOT USE THIS COMMAND
```

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run app.py
```

3. Open your browser to the URL shown in the terminal (typically `http://localhost:8501`)

## Requirements

See `requirements.txt` for the full list of dependencies:
- streamlit
- pandas
- numpy
- plotly
- networkx
- kaleido
- scikit-learn
- folium
- streamlit-folium

## Features

- Interactive dashboard for Research Culture Sustainability Index
- School-level and Division-level analysis
- Monte Carlo simulations
- Policy lever adjustments
- Data export functionality
